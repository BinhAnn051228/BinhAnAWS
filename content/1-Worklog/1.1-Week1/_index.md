### Week 1 Objectives:
* Attend internship orientation, learn the internship workflow and AWS Cloud fundamentals.
* Learn and practice Identity and Access Management (AWS IAM).
* Deploy Amazon EC2 virtual machines and configure Security Groups.
* Set up an Amazon VPC virtual network (Public/Private Subnets, Internet Gateway, Route Tables).
* Create Amazon S3 cloud storage and host a static website.
* Learn IAM Roles for EC2 and practice using the AWS CLI.
